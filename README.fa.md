# 🛡️ ErfSafe Linux — گاوصندوق امن + پلیر داخلی

> نسخه‌ی لینوکس **ErfSafe** — امنیت تمام برای نگهداری فایل‌های شما با فرمت اختصاصی `.erfsafe`
> **برنامه نویس : عرفان علیخانی** • 📢 [t.me/erftel](https://t.me/erftel) • 💻 [t.me/erfdev](https://t.me/erfdev)

---

## ✨ امکانات

| تب | توضیح |
|---|---|
| 🔒 **رمزنگاری** | قفل هر فایل با **AES-256-GCM** (رمزنگاری نظامیِ احراز اصالت‌شده) و فرمت اختصاصی `.erfsafe` |
| 🔓 **بازگشایی** | استخراج فایل فقط با رمز صحیح — تگ GCM هر دست‌کاری‌ را رد می‌کند |
| 🎬 **پلیر مدیا** | پخش فیلم (H.264, H.265/HEVC, MKV, AV1, WMV, …) و نمایش عکس **مستقیم از داخل فایل قفل‌شده** |
| 🔥 **امحا** | نابودسازی دائمی ۳ مرحله‌ای با استاندارد DoD |
| ℹ️ **درباره** | معرفی و لینک‌های سازندگان |

ویژگی‌های کلیدی:

- **سازگاری کامل دوطرفه با نسخه‌ی ویندوز** — فایلی را که در ویندوز قفل کردی در لینوکس باز کن (و برعکس)
- **پلیر داخلی با موتور FFmpeg جاسازی‌شده** — هیچ کدکِ خارجی لازم نیست؛ حتی فیلم‌های HEVC و MKV
- **درگ‌اند‌دراپ** فایل `.erfsafe` روی برنامه → پخش فوری
- صدا با **ALSA** + سینک دقیق تصویر و صدا + پخش/توقف/برگشت/جستجو (Seek)
- رابط گرافیکی **GTK3** با تم آبی شیک و کاملاً فارسی

## 🚀 اجرای سریع

```bash
tar xzf ErfSafe-Linux.tar.gz
cd ErfSafe-Linux
chmod +x ErfSafe
./ErfSafe
```

### نصب سیستمی (اختیاری)

```bash
./install.sh        # کپی در /usr/bin + ثبت در منوی برنامه‌ها
erfsafe             # اجرا از هرجا
```

### نیازمندی‌ها

روی اکثر توزیع‌ها از قبل نصب است: `gtk3`, `alsa`, `openssl`.
اگر نبود (اوبونتو/دبیان):

```bash
sudo apt install libgtk-3-0 libasound2 libssl3
```

## 🧩 حالت خط فرمان (بدون باز شدن رابط گرافیکی)

```bash
# قفل کردن یک فایل
./ErfSafe --encrypt in.file out.erfsafe "password"

# باز کردن یک گاوصندوق در یک پوشه (نام فایل اصلی به‌صورت خودکار برمی‌گردد)
./ErfSafe --decrypt out.erfsafe /home/user/Docs "password"

# تست خودکار (رمزگشایی + ۲ ثانیه پخش سایلنت برای بررسی موتور)
./ErfSafe --selftest out.erfsafe "password"
```

## 🔐 (نسخه‌ی ویندوز)

- **AES-256-GCM** با کلید ۲۵۶ بیتی
- **PBKDF2-HMAC-SHA512 با ۱۵۰٬۰۰۰ دور** (صنعتی، ضد بروت‌فورس/GPU)
- **Salt** تصادفی ۳۲ بایتی به‌ازای هر فایل + Nonce تصادفی ۱۲ بایتی
- **AAD**: نام فایل اصلی (جلوگیری از جعل نام)
- هر دستکاری = خطای «رمز اشتباه یا فایل دست‌کاری‌شده» (احراز اصالت GCM)
- ساختار فایل: هدر `ERFS` + نام فایل UTF-8 + متن رمزنگاری‌شده

> ⚠️ هیچ بخش مهمی (کلید، رمز عبور) روی دیسک ذخیره نمی‌شود؛ فقط رمزی که خودت نیار داری فایل را باز می‌کند. **اگر رمز را فراموش کنی هیچ‌کسی نمی‌تواند بازش کند.**

## 💡 نکات و ترفندها

- **پخش از حافظه فایل رمزنگاری‌شده**: در تب «پلیر مدیا» فایل `.erfsafe` + رمز را وارد کن → یک فایل موقت در `/tmp` ساخته و پخش می‌شود و موقع بستن به‌صورت امن پاک می‌شود
- **حق دسترسی فایل قفل `/000600`**: فایل‌های خروجی فقط برای خودت خواندنی‌اند
- کلید `Ctrl`+`+`/`Ctrl`+`-` روی پنجره برای بزرگنمایی قابل استفاده است (از امکانات GTK)
